# CRM: подключение к Supabase

## Статус
- Проект Supabase: `googl table` (ID: `yoqejkedmksmvbqagqru`)
- Адрес API: `https://yoqejkedmksmvbqagqru.supabase.co`
- Веб-приложение использует **публичный publishable key**, не service-role.
- Auth: email/password. Подтверждение email регулируется настройками Supabase Auth.
- Данные хранятся в PostgreSQL. Временные демонстрационные данные из localStorage больше не используются.
- RLS: каждый сотрудник видит только **свои** записи. Общая база компании с ролями будет настроена отдельным этапом.

## Запуск
```bash
npm install
npm run dev
```
Открыть http://localhost:3000. Зарегистрировать пользователя через форму входа.
В Supabase → Authentication → Providers → Email проверьте настройки регистрации и подтверждения почты.

## Безопасность
Никогда не добавляйте в репозиторий service_role, secret key или пароли.
Публичный publishable key разрешено использовать в браузере при корректно настроенном RLS.
Для реальной командной работы потребуется модель организаций, приглашения сотрудников, роли и дополнительные политики RLS.

## Развёртывание
Приложение пока не опубликовано на хостинге. Для публикации можно подключить репозиторий к Vercel или иному хостингу Next.js. При необходимости настроить Supabase Auth redirect URLs на адрес развёртывания.
