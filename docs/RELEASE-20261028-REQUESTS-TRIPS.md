# Заявки, распределение и компактные рейсы — 28 октября 2026

Отдельный раздел «Заявки» создаёт полную заявку с серверной автоматической нумерацией. Фильтры: заказчик, услуга, объект, машина, водитель и период. В «Распределении» выбирается существующая заявка и назначаются машина и водитель. Используется прежняя модель данных, без дублирования заявок: заявка → назначение/смена → результат → рейс → документы и начисления. Из заявки открываются связанные рейсы; из рейса — исходная заявка. Удалённые рейсы исключены из отображаемых результатов, но исходные записи сохраняются для защиты истории и финансовых ограничений.

В «Рейсах» основное меню автоматически скрывается, открываясь кнопкой вверху. Фильтры: заказчик, объект, период и даты; поиск по номеру рейса убран. Таблица уплотнена, документы раскрываются кнопкой «+», добавлена пагинация. Заголовки можно переставлять, границы столбцов — растягивать; для телефона есть кнопки перестановки. Вид таблицы сохраняется в браузере. Настройки Google Диска спрятаны за значком, фоновая синхронизация продолжает работать.

Исправлена причина устаревшей информации в мобильной «Смене»: старый отчёт, чьи файлы связаны исключительно с удалёнными рейсами, больше не показывается водителю. Самостоятельные отчёты и административный аудит сохраняются. История смен свёрнута отдельно от текущей смены.

Проверено: рабочая папка удалённого рейса №101 и его отдельные папки счёта/УПД пусты. Ранее исключённые документы за 26 октября остаются в отдельном архиве; они не входят в текущие документы рейсов. Автоматическая запись реестра в Google Sheets всё ещё ограничена отключённым Google Sheets API в пользовательском Google Cloud проекте; Google Drive подключён, загрузка и очистка его документов работают независимо.
