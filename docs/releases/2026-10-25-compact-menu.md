# Компактное левое меню и прокрутка карточки водителя

Пункты меню стали компактнее: вертикальные отступы 10 px вместо 13 px, промежутки 2 px вместо 4 px, единый шрифт 12 px. Уменьшены отступы у логотипа и подписи меню. Навигация занимает оставшуюся высоту и сохраняет собственную прокрутку, а блок «Компания / Выйти» не сжимается и закреплён ниже; нижний отступ панели 12 px вместо 23/22 px. Изменения действуют на desktop и в мобильном выдвижном меню. Порядок разделов и существующий дизайн сохранены.

Проверка: production build/TypeScript; браузерная проверка размеров панели/пунктов и доступности блока выхода при обычной и малой высоте, мобильного меню, отсутствия горизонтального переполнения. Данные, API, расчёты и SQL не изменены; миграции не требуются. Исходники восстановить из точного commit в архивном RELEASE-STATUS.md: npm ci && npm run build, прежние настройки Render, npm start -- --hostname 0.0.0.0. Откат интерфейса на предыдущий commit не требует отката базы.

## Напоминание о приложении водителя

Веб-кабинет: https://respectlogistic.onrender.com/driver . Логин виден в «Сервис и водители → Доступ водителей». Создание/сброс доступа: выбрать водителя собственного автопарка, задать логин латиницей/цифрами от 3 символов и временный пароль от 12 символов, передать лично. При первом входе требуется смена пароля. Старый пароль не отображается и не восстанавливается; сброс завершает текущие сеансы, поэтому без просьбы конкретного водителя сброс не выполнялся.

Последний проверенный Android-артефакт: respectlogistic-driver-unsigned-not-installable-3, Actions run 40046233910. Успех проверки сборки не означает готовый установщик. Настройка постоянной подписи: docs/android-signing-setup.md и scripts/configure-android-signing.py, затем GitHub Actions → Driver Android APK → Run workflow → respectlogistic/customers → signed=true. Текущая интеграция возвращает HTTP403 при чтении GitHub Actions secrets; необходим собственный доступ Secrets write. Ключи/пароли не создавались, не сбрасывались и не публиковались. Веб-кабинет работает независимо от подписи APK; фоновые push при закрытом приложении пока не подключены.

## Карточка водителя

В общей форме «ТС и водители» прокрутка вынесена из fieldset в отдельную div.form-body. Длинная карточка водителя прокручивается до заметок, заголовок и кнопки остаются доступными; блокировка полей на время сохранения сохранена. Тот же контейнер применяется к карточке собственной техники и другим формам этого раздела. Browser regression проверяет колесо, нижние поля, сохранение и повторное открытие карточки на desktop/mobile. Проверки API синтетические, пароли и реальные водительские карточки не изменялись.
