# Настройка подписи Android на Windows

Скрипт configure-android-signing.py останавливался на Windows с AttributeError: os.geteuid недоступен. Добавлена отдельная ветка Windows: защищённый ACL новой пустой папки разрешает доступ только текущему пользователю и SYSTEM; владелец и защита ACL проверяются. Папка с существующими файлами не изменяется. На POSIX сохранены проверки владельца/прав и umask. Парольные значения не передаются в аргументах процессов и не печатаются. Проверка GitHub выполняется до запроса пароля/создания ключа, существующие локальные/удалённые ключи не перезаписываются.

Добавлены тесты Windows-ветки без POSIX API, отказа менять непустую папку, защиты локального/удалённого ключа, stdin-передачи секретов и полной генерации/экспорта одноразового тестового ключа настоящим keytool. GitHub-команды перехватываются тестом, реальные Secrets не меняются. CI запускает тесты на windows-latest и ubuntu-latest с JDK17/Python3.13. Результат настоящей пользовательской подписи/APK подтвердить после повторного запуска исправленного скрипта пользователем.

SQL/API/CRM-данные не изменены, миграции не требуются. Для обновления пользовательского checkout: git pull --ff-only. Если постоянный ключ ещё не создан, запуск с --create --build из docs/android-signing-setup.md. Если ключ существует, повторный --create запрещён: сохранить и использовать оригинал. Откат скрипта — предыдущий commit, ключи/Secrets не удалять. Точный commit и проверки в архивном RELEASE-STATUS.md. Архив содержит только исходники/проверки и не содержит ключа/паролей или БД клиентов.
