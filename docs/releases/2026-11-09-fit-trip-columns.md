# Компактные строки и все столбцы рейса по ширине экрана

По просьбе пользователя уменьшены отступы строк таблиц. Для рейсов добавлен включённый по умолчанию режим «По ширине экрана»: на компьютере от 1101 CSS px все 15 столбцов (выбор, 13 полей и действия) пропорционально занимают доступную ширину без горизонтальной прокрутки. Отдельно уменьшены шрифт, отступы и кнопки рейсов, дата показана ДД.ММ.ГГГГ, цены и суммы — без лишних нулевых копеек и повторения обозначения рубля (валюта остаётся в заголовке). Расчёты и числовые значения не изменены, полная денежная запись доступна в подсказке.

Перенос текста по умолчанию выключен для компактных строк; явный выбор пользователя из БД сохраняется. Длинные адреса и имена в однострочном режиме доступны в подсказках. На телефоне и узком окне сохраняется прокрутка таблицы шириной минимум 1100 px. Нельзя одновременно показать все поля читаемым шрифтом на экране телефона.

Режим можно выключить, чтобы вернуть абсолютные ширины столбцов. Порядок и ранее сохранённые ширины сохранены. Настройка trips.fitWidth использует существующую owner-scoped запись в respectlogistic_user_settings; БД, RPC и миграции не изменялись. Настройки не записываются в браузер. Проверены подгонка и видимость действий на desktop, закрепление, старый режим прокрутки, сохранение выбора в чистом браузере, документы рейса и связи заявок.

Точные commit/deploy и результаты проверок находятся в журнале выпуска на Диске. Скриншоты и browser fixtures содержат только синтетические данные; настоящая сессия владельца не использовалась. Для восстановления распаковать архив точного commit, npm ci, вернуть существующие секреты Render отдельно, npm run build и развернуть ветку respectlogistic/customers на существующем сервисе. Новых миграций нет. Откат интерфейса — 0c867ebea3b4a19f37d2f02c09c05e2369c7c123; данные и таблицу настроек не удалять. Архив исходников не является резервной копией клиентской БД.
