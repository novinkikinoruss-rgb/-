# Исправлена прокрутка формы заявки

В «Распределение → Создать заявку» длинный fieldset не прокручивался колёсиком/жестом внутри flex-окна: нижние поля оказывались недоступны. Прокручиваемой областью теперь служит отдельный div.form-body; fieldset сохраняет блокировку полей на время сохранения. Заголовок и кнопки сохранения остаются вне прокрутки. Внешний вид сохранён, изменения относятся только к форме создания/редактирования заявки.

Проверка воспроизводит исходную ошибку колёсиком без фокусировки нижних полей (которая скрывала дефект в прежнем сценарии). После исправления проверены фактический scrollTop, доступность последнего поля «Комментарий» и кнопки сохранения, возврат к началу и создание заявки на desktop/mobile; сохранены существующие проверки назначения, продления и печати. Сборка проверяет TypeScript. Сквозные сценарии используют синтетические auth/API ответы.

Изменения схемы/данных БД и новые SQL-миграции не требуются. Восстановление: npm ci && npm run build, существующее окружение Render, ветка respectlogistic/customers. Для отката интерфейса восстановить предыдущий commit; данные не изменяются. Точный commit, Render deploy и результаты публикации находятся в архивном RELEASE-STATUS.md.
