# Фильтры сверху и таблицы на всю ширину

По уточнению пользователя фильтры рейсов и заявок перенесены из правой колонки наверх. Панель фильтра и таблица занимают всю ширину рабочей области. На компьютере поля располагаются горизонтально с автоматическим переносом, на телефоне — по два в ряд. Кнопки применения и сброса расположены рядом. Сохранены закрепление заголовков, прокрутка, настройки ширины столбцов и сохранение вида в БД.

Изменение касается только оформления. Миграции, данные, правила расчётов и авторизация не изменялись. Проверки существующего интерфейса обновлены для верхнего расположения фильтра и равной ширины панели/таблицы. Браузерные проверки используют синтетические данные и подмену Auth/RPC; реальная сессия владельца не используется. Точные результаты, commit, deploy и SHA256 архива указаны в журнале выпуска на Google Диске.

Для восстановления: распаковать архив точного commit, npm ci, восстановить существующие секреты отдельно, npm run build, развернуть существующий сервис respectlogistic.onrender.com из ветки respectlogistic/customers. Новых миграций нет, текущую схему и таблицу respectlogistic_user_settings сохранить. Для отката оформления — commit 385bd935456ec9ad4ce8060183f6af28f8a016cb. Архив исходников не является резервной копией клиентской БД.
