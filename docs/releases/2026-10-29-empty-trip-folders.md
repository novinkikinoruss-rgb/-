# Удаление пустых папок рейсов

При синхронизации Google Диска после очистки файлов удалённого/отменённого рейса проверяются его папки с меткой respectlogistic_trip_folder. Пустая папка перемещается в корзину, включая папки, оставшиеся от предыдущих синхронизаций. Общие уровни заказчика/объекта/услуги/даты/машины не удаляются. Папки с оставшимися файлами или вложенными папками сохраняются. Корневая папка, папки вне CRM документы, папки действующих рейсов и папки без подтверждённой метки не затрагиваются. Неполная или неудачная проверка содержимого не считается пустотой.

Очистка использует существующую синхронизацию: раз в минуту при открытом разделе «Рейсы» либо по кнопке «Синхронизировать сейчас» за значком Google Диска. Google Sheets API не требуется для очистки папок Drive. Окончательное уничтожение из корзины не выполняется.

Проверки: 11 тестов экспорта/очистки Drive, включая пагинацию папок, старую пустую папку, чужой корень, действующий рейс, ручные файлы, вложения и ошибку Google; полный npm test и TypeScript. Точный commit, CI и подтверждение публикации — в отдельном отчёте проверки в архиве Google Drive. Изменений схемы БД нет, SQL-миграция не требуется.

Восстановление: исходники точного commit из архива, npm ci, отдельно восстановить настройки/секреты Render, npm test и npm run build, развернуть на существующем сервисе. Архив не содержит клиентской базы или Google OAuth-секретов. Предыдущий commit: dec911ec80feecec33bf2dc1936509b2536c9bb8. Откат к нему прекращает очистку папок; папки из корзины можно восстановить штатными средствами Google Drive.
