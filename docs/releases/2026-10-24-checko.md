# Чекко — реквизиты заказчиков по ИНН

Заменён провайдер автозаполнения реквизитов заказчика: Чекко вместо DaData. API /api/company проверяет вход через существующую Supabase-сессию, контрольную сумму ИНН из 10 цифр и совпадение ИНН в ответе провайдера. Данные получаются только сервером через https://api.checko.ru/v2/company. CHECKO_API_KEY задаётся непосредственно в окружении сервиса Render respectlogistic; ключ отсутствует в исходниках и клиентских ответах. URL провайдера и необработанные сообщения об ошибках не логируются и не возвращаются клиенту.

Форма позволяет найти юридическое лицо по ИНН, выбрать результат и заполнить краткое/полное наименование, ИНН, КПП, ОГРН, юридический адрес и руководителя. Кнопка «Заполнить по ИНН» и заполнение после выхода из поля ИНН также используют Чекко. Сохранение выполняется только пользователем, контактные и банковские поля не заменяются. Бело-зелёный дизайн сохранён. Поиск по названию и ИП в этом выпуске не поддерживаются. Проверка означает контрольную сумму ИНН и наличие организации; скоринг благонадёжности не реализован.

Ключ проверен реальным запросом: HTTP 200, meta.status=ok, реквизиты организации получены. Официальная страница документации checko.ru/integration/api недоступна из среды (403); формат подтверждён реальным ответом API провайдера. Настроенный ключ записан на Render с merge, остальные переменные не заменялись. База данных, схема, RLS и сохранённые карточки не менялись; SQL-миграции не требуются.

Проверки: npm test, npm run build, desktop/mobile browser tests customer-search и customers. Серверные тесты покрывают отсутствие/истечение сессии, контрольную сумму, несовпадение ИНН, отсутствие результатов, ограничения API, ошибочный ключ и исключение секретов из ошибок. Браузерные тесты используют фикстуры; полная проверка под производственной учётной записью пользователя не выполнялась. Точные результаты и commit приведены в сопровождающем журнале выпуска.

Восстановление: распаковать архив, npm ci, настроить серверные Supabase-переменные и CHECKO_API_KEY в Render, npm run build. Исходники не содержат ключ, .env, node_modules или записи клиентской базы. Архив не является резервной копией базы. Предыдущий код: 825c26a0da102a738ab65c07f5c5db520a19bd80 (DaData; для работы требует собственного DADATA_API_KEY).
