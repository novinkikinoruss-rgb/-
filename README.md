# Транспорт CRM

CRM для транспортно-логистической компании. Интерфейс на русском языке.

## Рабочее приложение

https://transport-crm-ij9v.onrender.com

Первый запрос к бесплатному Render-сервису после простоя может выполняться дольше обычного.

## Технологии

- Next.js 15, React 19, TypeScript, Tailwind CSS
- Supabase PostgreSQL с Row Level Security (изоляция данных по пользователю)
- Supabase Auth (вход по email и паролю)
- Supabase Storage (закрытое хранилище документов)
- GitHub (исходный код), Render (развёртывание)

## Разделы

- Главная панель: рейсы, плановая выручка и маржа, задачи
- Заказчики: создание, поиск, редактирование, удаление
- Перевозчики, автопарк, водители: реестры с CRUD
- Заявки и рейсы: создание, поиск, изменение статуса
- Диспетчеризация: назначение перевозчика, машины и водителя
- Бухгалтерия: фактические поступления и расходы
- Документы: приватная загрузка и скачивание
- Задачи и аналитика

## Локальный запуск

```bash
npm install
npm run dev
```

Для сборки: `npm run build`. Для запуска production: `npm run start`.

## Важно

- Данные хранятся в Supabase, а не в GitHub или Render.
- Публичный publishable-ключ Supabase в клиентском коде не является секретом; защиту обеспечивает RLS.
- Никогда не добавляйте в GitHub service_role-ключи, токены или пользовательские пароли.
- Регистрация пользователей доступна через интерфейс; перед рабочим запуском настройте правила доступа сотрудников.
- Приложение находится в стадии тестирования; не считайте финансовые расчёты бухгалтерской отчётностью.

## Проверки изменений бухгалтерии

Подготовленная ветка и PR: https://github.com/novinkikinoruss-rgb/-/pull/1

Для воспроизводимой установки используйте Node 22.18+ и `npm ci`. Проверки: `npm test`, `npm run lint`, `npm run build`; браузерные сценарии: `npx playwright install chromium` и `npm run test:e2e`. GitHub Actions также проверяет SQL на отдельном PostgreSQL.

Сценарии, установка дополнения схемы и ограничения описаны в [docs/accounting-workflow.md](docs/accounting-workflow.md), результаты — в [docs/build-verification.md](docs/build-verification.md). Изменения требуют обновления схемы до развёртывания нового интерфейса.
