# CRM транспортной компании

Стартовый проект CRM для логистики.

## Модули MVP
- Клиенты и контакты
- Заявки на перевозку
- Перевозки и статусы
- Задачи менеджеров
- Пользователи и роли

## Стек
Frontend: React + TypeScript (план)
Backend и БД: Supabase PostgreSQL (план)
GitHub: исходный код

> База данных и авторизация пока не подключены. Не размещайте пароли и ключи API в репозитории.

Текущий стек: Next.js, Supabase, Render.
